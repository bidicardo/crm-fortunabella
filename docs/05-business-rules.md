# Общие бизнес-правила

## Клиенты

- Один клиент может иметь несколько сделок.
- Повторная заявка существующего клиента создаёт новую сделку.
- По канбану перемещаются сделки.
- Телефон клиента приводится к единому формату.
- Система предупреждает о возможном дубле.
- Любой пользователь CRM может объединить две карточки клиентов.
- При объединении сделки, задачи, документы и история переносятся на основного клиента.
- Объединённая карточка не удаляется безвозвратно, а архивируется.
- Клиент отображается в карточке сделки

## Сделки

- У сделки один клиент.
- У сделки один связанный контрагент.
- Сделка содержит дату проведения.
- Сделка автоматически появляется в календаре после создания.
- Сделка со статусом «Отказ» не отображается в календаре по умолчанию.
- Любую сделку можно переместить в любую стадию.
- Система не блокирует ошибочные переходы, но показывает предупреждения.
- Если дата занята, сохранение разрешается.
- При занятой дате показывается маленький жёлтый треугольник с восклицательным знаком на той же строке где поле даты.
- При наведении или нажатии отображается предупреждение о другом мероприятии.

## Предоплата

- Предоплата содержит сумму.
- Предоплата содержит статус: оплачено или не оплачено.
- Предоплата имеет держателя из пользователей CRM.
- Стадия «Бронь» означает подтверждённое мероприятие.
- Перед переходом в «Бронь» система предупреждает, если предоплата не отмечена как оплаченная.
- Предупреждение не блокирует переход.

## Документы

- Документ может быть связан со сделкой.
- Документ может быть связан с клиентом.
- Документ может быть связан с контрагентом.
- Документ можно загрузить и скачать с телефона.
