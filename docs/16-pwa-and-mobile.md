# PWA и мобильная версия

## Обязательные требования

- Интерфейс работает в Safari на iPhone.
- CRM устанавливается на домашний экран.
- Все страницы адаптированы под мобильный экран.
- Канбан работает на сенсорном экране.
- Карточки можно открывать и редактировать.
- Календарь не требует горизонтальной прокрутки.
- Таблицы адаптированы под телефон.
- Документы можно загружать и скачивать с телефона.
- Работает тёмная тема.
- Push-уведомления работают для установленной PWA.

## Навигация на телефоне

- Левое меню на узком экране скрыто; вместо него нижняя панель вкладок:
  Главная, Сделки, Клиенты, Задачи, Ещё (состав меню — `docs/17-ui-screens.md`).
- «Ещё» открывает остальные разделы: Контрагенты, Действующие
  контрагенты, Календарь, Документы.
- Нижняя панель учитывает безопасную зону iPhone (индикатор «домой»),
  вкладки не меньше 44 px по высоте.
- Верхняя панель (название раздела, колокольчик, меню пользователя)
  остаётся на телефоне.

## Режим работы

Достаточно работы при наличии интернета.

## Канбан на телефоне

Нужно предусмотреть:
- drag-and-drop касанием;
- альтернативную кнопку смены этапа;
- горизонтальную прокрутку колонок либо
  другой удобный мобильный режим;
- открытие карточки одним касанием;
- отсутствие слишком мелких кнопок.

## Push

Используются для:
- новых заявок;
- задач;
- мероприятий.

Если пользователь отказал в разрешении:
- приложение продолжает работать;
- в настройках отображается инструкция
  по повторному включению уведомлений.
