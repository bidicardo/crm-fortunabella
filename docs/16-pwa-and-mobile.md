# PWA и мобильная версия

## Обязательные требования

- Интерфейс работает в Safari на iPhone.
- CRM устанавливается на домашний экран.
- Все страницы адаптированы под мобильный экран.
- Канбан работает на сенсорном экране.
- Карточки можно открывать и редактировать.
- Календарь не требует горизонтальной прокрутки.
- Таблицы адаптированы под телефон.
- Документы можно загружать и скачивать с телефона.
- Работает тёмная тема.
- Push-уведомления работают для установленной PWA.

## Навигация на телефоне

- Левое меню на узком экране скрыто; вместо него нижняя панель вкладок:
  Главная, Сделки, Клиенты, Задачи, Ещё (состав меню — `docs/17-ui-screens.md`).
- «Ещё» открывает остальные разделы: Контрагенты, Действующие
  контрагенты, Календарь, Документы.
- Нижняя панель учитывает безопасную зону iPhone (индикатор «домой»),
  вкладки не ниже 56 px (цель касания не меньше 44 px).
- Нижняя панель и левое меню переключаются только CSS (по ширине 768 px),
  без определения размера экрана скриптом.
- Верхняя панель (название раздела, колокольчик, меню пользователя)
  остаётся на телефоне.

## Правила вёрстки для iPhone

Общие для всех экранов (реализованы в общем CSS и layout):
- `viewport-fit=cover` в `<meta name="viewport">`, отступы под индикатор
  «домой» через `env(safe-area-inset-bottom)`; у области содержимого на
  телефоне нижний отступ под панель вкладок.
- Высота страницы — `min-h-dvh` (не `min-h-screen`): на iPhone `100vh`
  выше видимой области, из-за чего появлялась лишняя прокрутка.
- Шрифт полей ввода, списков и текстовых областей на телефоне — 16 px,
  иначе Safari приближает страницу при фокусе на поле. Масштабирование
  щипком не отключается (доступность).
- Выпадающие списки (`select`) используют собственную серую стрелку:
  системная в тёмной теме на iOS чёрная.
- Горизонтальная прокрутка допускается только внутри блока (например,
  таблицы), не у всей страницы: длинный текст переносится (`break-words`),
  заголовок и кнопки на узком экране идут друг под другом.
- Элементы, скрытые Alpine (`x-show`), помечаются `x-cloak`, чтобы не
  мигать до запуска Alpine.
- `navigator.clipboard` в Safari работает только по HTTPS, поэтому кнопка
  «Копировать» (ссылка-приглашение) имеет запасной вариант через выделение
  текста; на боевом HTTPS-хостинге он не нужен.

## Проверка на реальном телефоне (локально)

Телефон и компьютер — в одной Wi-Fi/LAN сети; открыть `http://<IP компьютера>`.
Если не открывается: разрешить входящий TCP 80 в брандмауэре Windows для
«Частной» сети (сеть должна быть помечена как частная) и проверить, что
роутер не включает изоляцию клиентов. Полноценная проверка установки PWA
требует HTTPS (Фаза 10).

## Режим работы

Достаточно работы при наличии интернета.

## Канбан на телефоне

Нужно предусмотреть:
- drag-and-drop касанием;
- альтернативную кнопку смены этапа;
- горизонтальную прокрутку колонок либо
  другой удобный мобильный режим;
- открытие карточки одним касанием;
- отсутствие слишком мелких кнопок.

## Push

Используются для:
- новых заявок;
- задач;
- мероприятий.

Если пользователь отказал в разрешении:
- приложение продолжает работать;
- в настройках отображается инструкция
  по повторному включению уведомлений.
