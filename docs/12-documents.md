# Документы и договоры

## Назначение

CRM должна хранить договоры и другие документы,
связанные с клиентами, сделками и контрагентами.

## Поля документа

- Файл.
- Название.
- Связанный клиент.
- Связанная сделка.
- Связанный контрагент.
- Дата создания.
- Дата изменения.
- Тип договора.
- Дата окончания действия.

## Тип договора

- договор с клиентом;
- договор с контрагентом.

## Файлы

Разрешённые форматы:
- PDF;
- Microsoft Word.

Необходимо определить точный список расширений:
- .pdf;
- .doc;
- .docx.

## Возможности

- Все пользователи могут загружать документы.
- Все пользователи могут удалять документы.
- Все пользователи могут скачивать документы.
- Загрузка работает с телефона.
- Скачивание работает с телефона.
- Документы отображаются в карточке сделки.
- Документы отображаются в карточке контрагента.
- Документы отображаются в карточке клиента.

## Дата окончания

Поле «Актуален до» означает дату,
до которой действует договор.
