# Экраны системы

## Навигация и общий каркас

Все страницы после входа имеют единый каркас: левое меню, верхняя
панель и область содержимого. Страницы входа и регистрации по
приглашению — без каркаса.

### Левое меню (компьютер и планшет)

- Боковая панель своего цвета: в светлой теме светло-бежевая — того же
  цвета, что фигуры на странице входа (`#E7DFD5`), в тёмной — тёмная.
  Пункты меню и «Свернуть» — кнопки на подложке с тонкой рамкой, активный
  пункт залит цветом основной кнопки; название CRM, группы пунктов и
  «Свернуть» разделены линиями. Закреплена на высоту окна: кнопка
  сворачивания внизу видна на любой странице. Вверху — название продукта
  (Fortuna CRM).
- Пункты с иконками и подписями, сгруппированные под подзаголовками.
  Активный пункт подсвечен.
- Состав:
  - Главная;
  - группа «Продажи»: Сделки, Клиенты;
  - группа «Партнёры»: Контрагенты, Действующие контрагенты;
  - группа «Работа»: Задачи, Календарь;
  - Документы.
- Внизу панели кнопка сворачивания: свёрнутая панель показывает только
  иконки (у пункта при наведении подпись). Состояние запоминается в
  браузере. Группы всегда раскрыты.
- Пункт показывается, только когда соответствующий раздел уже
  реализован (мёртвых ссылок в меню нет).

### Верхняя панель

- Фон верхней панели (и нижней панели на телефоне) чуть темнее фона
  страницы.
- Слева — название текущего раздела («Клиенты», «Сделки» и т. д.).
- Справа — колокольчик уведомлений (появляется вместе с внутренними
  уведомлениями, см. `docs/14-notifications.md`) и меню пользователя.
- Меню пользователя: имя со стрелкой вниз, по нажатию раскрывается
  панель: профиль, тёмная тема, уведомления, Telegram, «Пользователи»
  (приглашения и блокировка, только для создателя), «Выйти».
- Глобального поиска и кнопки быстрого создания «+» в MVP нет.
- Стрелка «Назад» слева от названия раздела — **общее правило для всех
  страниц**. Она ведёт не на предыдущую страницу истории браузера, а в
  родительский раздел:
  - карточка, форма создания и редактирования → список своего раздела
    (например, карточка клиента → «Клиенты»), даже если пользователь
    только что сохранил форму;
  - список раздела и страницы, которых нет в меню («Пользователи»,
    профиль, уведомления, Telegram) → главная;
  - на главной стрелки нет.
  Родитель определяется автоматически по пункту меню
  (`App\Support\Navigation::backUrl()`, `config/navigation.php`): новые
  разделы получают стрелку без дополнительной настройки, если их
  маршруты подпадают под шаблон `active` пункта меню.

### Телефон (iPhone, PWA)

- Левое меню на телефоне не показывается. Вместо него нижняя панель
  вкладок: Главная, Сделки, Клиенты, Задачи, Ещё.
- «Ещё» открывает остальные разделы: Контрагенты, Действующие
  контрагенты, Календарь, Документы.
- Верхняя панель остаётся (название раздела, колокольчик, меню
  пользователя).
- Подробности — `docs/16-pwa-and-mobile.md`.

### Общие правила страниц

- Каждая страница задаёт название раздела (оно выводится в верхней панели
  и в заголовке вкладки «Раздел — Fortuna CRM»). Для карточки клиента в
  верхней панели «Клиент», а имя — только в заголовке карточки.
- Страницы входа, регистрации по приглашению и «Ссылка недействительна»
  используют отдельный layout `layouts/guest.blade.php` (Д2, референс 5):
  декоративный фон из полупрозрачных фигур, по центру логотип и название
  продукта, форма в карточке, под карточкой переключатель темы; без левого
  меню и нижней панели. Кнопка отправки во время запроса неактивна и
  показывает крутящийся значок. «Забыли пароль», открытой регистрации и
  входа через соцсети нет.
- Ширину содержимого задаёт сама страница (общего ограничителя нет).
- Правила вёрстки для телефона — `docs/16-pwa-and-mobile.md`.
- Оформление: после выполнения задачи «Дизайн-система» (Д1) новые экраны
  собираются только из её компонентов (кнопки, поля, флажки, метки,
  уведомления, таблицы), а цвета и шрифты берутся из общих переменных;
  собственных длинных наборов стилей на страницах не пишется. Порядок
  внедрения дизайна и референсы — `docs/26-ui-designe-plan.md`,
  `docs/design/`.

## Клиенты

Подробно — `docs/08-clients.md`, `docs/18-deduplication.md`.

- база клиентов (`/clients`): таблица с поиском, фильтром по типу,
  переключателем «Только архивные», сортировкой, выбором колонок,
  постраничным выводом;
- карточка клиента: данные, «Объединить с…», «Редактировать», история
  изменений (3 записи, «Показать ещё» — до 10 с прокруткой внутри блока,
  «Свернуть»);
- создание и редактирование клиента (одна форма, при создании —
  предупреждение о дубле);
- слияние дублей: выбор второго клиента → сравнение карточек → подтверждение.
