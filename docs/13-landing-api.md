# Интеграция с лендингом

## Источник

Лендинг:
https://fortunabella.ru

## Форма

Поля:
- имя;
- телефон;
- email;
- социальная сеть;
- описание запроса.

Обязательные поля:
- имя;
- телефон.
- описание запроса.

## Сценарий заявки

1. Пользователь заполняет форму на сайте.
2. Лендинг отправляет POST-запрос в CRM.
3. CRM проверяет секретный токен.
4. CRM проверяет обязательные поля.
5. CRM нормализует номер телефона.
6. CRM ищет клиента по телефону.
7. Если клиент найден, создаётся новая сделка.
8. Новая сделка связывается с найденным клиентом.
9. Если клиент не найден, создаются клиент и сделка.
10. Сделка получает статус «Новая заявка».
11. Исходная заявка сохраняется в журнале.
12. Пользователи получают уведомление.
13. Уведомление дублируется в Telegram.

## Дубликаты

Если телефон найден:
- не создавать нового клиента;
- создать новую сделку;
- связать сделку с существующим клиентом.

## Безопасность

- Секретный токен.
- Проверка формата входящих данных.
- Ограничение частоты запросов.
- Журнал успешных и ошибочных запросов.
- Защита от повторной обработки одного запроса.

## Нормализация телефона

Все номера приводятся к единому формату.
Нужно выбрать стандарт хранения,
например международный формат E.164.

Примеры:
- `89171234567`;
- `8 917 123-45-67`;
- `+7 917 123-45-67`.

Эти другие значения должны распознаваться
как один и тот же номер.
