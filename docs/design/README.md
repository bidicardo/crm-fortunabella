# Референсы дизайна

Здесь лежат материалы для оформления интерфейса. План внедрения дизайна,
порядок задач и правила работы с референсами — `docs/26-ui-designe-plan.md`.

## Структура

- `refs/` — скриншоты референсов (PNG или JPG).
- `icons/` — иконки отдельными файлами SVG, по одному на иконку.
- `NN-….md` — короткие спецификации и решения (уже есть `01-themes.md` — тёмная и светлая темы), которые пишутся по референсам перед
  реализацией (например, `01-design-system.md`): что берём, что не берём,
  вид на телефоне, тёмная тема. Спецификацию подтверждает владелец до кода.

## Правила

- В скриншотах не должно быть реальных персональных данных клиентов
  (правило проекта: реальные данные в репозиторий не попадают).
- Если референс — ссылка, рядом нужен скриншот.
- **Набор иконок — Lucide** (lucide.dev, лицензия ISC; решение владельца).
  Иконки на референсах используются как ориентир по стилю и составу; в
  проект попадают иконки Lucide (при отсутствии нужной — ближайшая из
  Tabler Icons, MIT, тонкий контур того же вида; смешивать другие наборы
  не нужно). Иконки берутся отдельными SVG с сайта набора, пакет
  `lucide` не устанавливается (правило проекта: без новых зависимостей).
  Рядом с иконками лежит `icons/LICENSE.md` с названием набора,
  адресом источника и текстом лицензии.
- Соответствие иконок референса Lucide (основные; полный список
  составляется в `01-design-system.md`): дом — `house`, календарь —
  `calendar`, лупа — `search`, плюс — `plus` и `circle-plus`, крестик —
  `x`, галочка — `check`, фильтр — `filter` и `filter-x`, загрузка —
  `download` и `upload`, почта — `mail`, замок — `lock`, выход —
  `log-out`, шестерёнка — `settings`, колокольчик — `bell-ring`,
  пользователь — `circle-user`, часы — `clock`, меню — `menu`, вопрос —
  `circle-help`, деньги — `circle-dollar-sign`, документ — `file-text`,
  сетка — `layout-grid`, график — `trending-up`, копирование — `copy`.
- Иконки: файлы SVG, один цвет (`currentColor`), без лишних размеров и
  текста; имена по назначению (`deals.svg`, `clients.svg`, `edit.svg`,
  `merge.svg`, `search.svg`, `close.svg`, `calendar.svg`, `bell.svg`,
  `filter.svg` и т. д.). Если иконки из открытого набора, достаточно
  указать набор, лицензию и названия нужных иконок. Пакеты иконок не
  устанавливаются: нужные иконки встраиваются в код как SVG.
- Референс описывает вид, а не логику: тексты, поля и поведение берутся из
  `docs/`.
