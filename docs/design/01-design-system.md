# Дизайн-система (Д1а) — спецификация

Этап 1 (спецификация, без кода) задачи Д1
(`docs/prompts/prompts-designe/01-design-system.md`). Источники: референс 1
(`refs/01-design-system-dark-theme.png`, `refs/01-design-system-light-theme.png`),
решения по темам `docs/design/01-themes.md`, план `docs/26-ui-designe-plan.md`,
мобильные правила `docs/16-pwa-and-mobile.md`, экраны `docs/17-ui-screens.md`,
текущие `resources/css/app.css`, `vite.config.js`,
`resources/views/components/*`, `layouts/*`, `livewire/*`.

Весь контраст ниже посчитан по формуле WCAG (относительная светимость,
`(L1+0.05)/(L2+0.05)`), не на глаз. Норма: не ниже 4.5:1 для обычного
текста, не ниже 3:1 для значков, рамок интерактивных элементов и крупного
жирного текста.

Спецификацию нужно подтвердить до начала Этапа 2 (кода). В конце —
раздел «6. Отступления от референса» — их нужно подтвердить отдельно,
это не просто перенос картинки в переменные.

## 2. Типографика

**Шрифт:** Inter, начертания Regular 400, Semibold 600, Bold 700;
поддерживает кириллицу; лицензия OFL (свободная) — решение владельца,
`docs/26-ui-designe-plan.md` вопрос 2. Подключается через `bunny()`
в `vite.config.js`, тем же способом, что и текущий Instrument Sans
(**заменяет** его — см. §6.5).

Из референса взяты две группы размеров: **заголовки** (трекинг −0.5px)
и **текст** (трекинг −0.1px). Плотный интерфейс CRM не использует самые
крупные заголовки референса (48/34px) — они остаются доступными
токенами на будущее (см. §6.4), практически применяются H3/H4:

| Токен | Размер / высота строки / трекинг | Начертание | Применение |
|---|---|---|---|
| `--text-h1` | 48px / 56px / −0.5px | Bold 700 | не используется в MVP (заготовка) |
| `--text-h2` | 34px / 40px / −0.5px | Bold 700 | не используется в MVP (заготовка) |
| `--text-h3` | 22px / 26px / −0.5px | Semibold 600 | заголовок раздела/карточки (имя клиента, «Сотрудники» и т. п.) |
| `--text-h4` | 17px / 20px / −0.5px | Semibold 600 | заголовок диалога/подраздела |
| `--text-body-lg` | 22px / 32px / −0.1px | Regular 400 | не используется в MVP (заготовка) |
| `--text-body-md` | 17px / 24px / −0.1px | Regular 400 | текст форм и кнопок покрупнее (по месту) |
| `--text-body` | 15px / 22px / −0.1px | Regular 400 | основной текст интерфейса (таблицы, поля, кнопки) |
| `--text-caption` | 13px / 20px / −0.1px | Regular 400 | подписи, даты, второстепенный текст |

Сочетание «заголовок + пояснение» (например, плашка уведомления,
пустое состояние): `--text-h4` + `--text-caption` цветом
`--color-text-secondary`.

## 4. Элементы и состояния

Отступы и радиусы — новые токены (сетка отступов Tailwind остаётся как
есть, шаг 0.25rem, отдельных токенов не заводим):

| Токен | Значение | Применение |
|---|---|---|
| `--radius-sm` | 6px | чекбокс, метка-статус |
| `--radius-md` | 8px | кнопки, поля, выпадающие списки |
| `--radius-lg` | 14px | карточки, панели, модальные окна, уведомления |
| `--radius-full` | 999px | переключатель, аватар |
| `--shadow-panel` (светлая) | `0 4px 16px -4px rgb(0 0 0 / .12)` | выпадающие панели, поверх `border` |
| `--shadow-panel` (тёмная) | `0 4px 16px -4px rgb(0 0 0 / .4)` | то же, тень слабее видна, граница обязательна |

### Кнопки

Варианты: основная (Primary, заливка), вторичная (Secondary, рамка),
опасная (Danger, заливка), текстовая (Text, без фона и рамки), иконочная
(Icon, квадрат 44×44px минимум).

| Состояние | Primary | Secondary | Danger | Text |
|---|---|---|---|---|
| Обычное | фон `accent`, текст белый | рамка `border`, текст `text` | фон `danger-fill` (`#C62828` обе темы), текст белый | текст `accent`, подчёркивание при наведении |
| Наведение | темнее на 1 шаг (Blue → Dark blue в тёмной; `accent-hover` в светлой) | фон `bg-surface` | темнее на 8% | подчёркнут |
| Фокус | рамка фокуса (§1.4) поверх всех состояний | — | — | — |
| Нажатие | ещё темнее (`accent-active` / Dark blue) | фон чуть темнее `bg-surface` | ещё темнее | — |
| Отключено | непрозрачность 50%, курсор `not-allowed`, без наведения | то же | то же | то же |

Иконка в кнопке — слева или справа от текста, `gap: 0.5rem`, размер
16–18px.

### Поле ввода / текстовая область

Высота ≥ 44px (кроме десктопных плотных списков, где допускается 40px
вне зоны касания), радиус `--radius-md`, рамка `--color-border`, фон
`--color-bg-surface`. Шрифт `--text-body`; на телефоне 16px — правило в
`app.css` не трогаем.

| Состояние | Вид |
|---|---|
| Обычное | рамка `border`, текст `text`, плейсхолдер `text-muted` |
| Фокус | рамка фокуса (§1.4) |
| Ошибка | рамка `error`/`danger-fill`, текст подсказки тем же цветом снизу, `aria-invalid="true"` |
| Отключено | фон чуть светлее/темнее, текст `text-muted`, курсор `not-allowed` |

### Выпадающий список (select)

Как поле ввода; текущая своя серая стрелка в `app.css` сохраняется без
изменений (правило для iOS).

### Флажок / радиокнопка / переключатель

16×16px (флажок, радио), область клика ≥ 44px через `label`. Отмеченное
состояние — заливка `accent`, галочка/точка белая. Переключатель (switch)
28×16px трек, `radius-full`, заливка `accent` во включённом состоянии.

### Метка-статус (badge)

Маленькая плашка: текст + точка (или без неё), фон — тон 10% цвета
поверх `bg-surface`, текст и рамка — сам цвет. Используется для «архив»,
статусов приглашения, этапов (§1.3).

### Уведомление (alert), 4 вида

Успех/предупреждение/ошибка/информация: рамка слева 3px цветом кода,
фон — тон 10% того же цвета, иконка соответствующего вида (§3), заголовок
`--text-h4`, текст `--text-caption` или `--text-body`, `role="alert"` для
ошибок и предупреждений.

### Блок-карточка с заголовком

Фон `bg-surface`, радиус `--radius-lg`, отступ 16–24px, граница `border`
(1px), заголовок `--text-h3`.

### Таблица

Шапка — фон `bg-surface`, текст `--text-caption` полужирный; строки —
разделитель `border` снизу; наведение строки — `bg-surface`. Пустое
состояние — текст `text-secondary` по центру ячейки/блока.

### Пустое состояние

Иконка (по месту, 32–40px, `text-muted`) + `--text-h4` + пояснение
`--text-caption` цветом `text-secondary`, по центру блока.

### Поле карточки (только чтение)

Подпись и значение в рамке — как поле формы редактирования (рамка
`border`, фон `bg-surface`, радиус `--radius-md`). Пустое значение — «—».
Карточка раскладывает поля так же, как форма редактирования.

### Каркас: левое меню, верхняя и нижняя панели

Левое меню — токены `--color-sidebar-*`: светлая тема — коричневое
(`#904D30`, наведение/активный `#7A3F26`, текст `#F4E6DC` 5.2:1, подписи
групп `#E6DAC8` 4.6:1, активная иконка и рамка фокуса `#FAF9F6` 6.1:1),
тёмная тема — `#131516`, `#1B1F27`, `#A0AEC0`, `#718096`, `#5D88F4`.
Закреплено на высоту окна. Верхняя и нижняя панели — `--color-bar`
(светлая `#F4F1EA`, тёмная `#0E0F10`), чуть темнее фона страницы.

### Выпадающая панель (меню пользователя, «Колонки», «Ещё»)

Фон `bg-surface`, рамка `border`, радиус `--radius-lg`, тень
`--shadow-panel`, пункт — `min-height: 44px`, наведение — фон чуть темнее
(тёмная) / чуть темнее (светлая).

## 6. Отступления от референса (нужно подтвердить)

1. **Кнопка Primary по умолчанию — Dark blue `#162BA9`, не Blue
   `#029CF5`.** Белый текст на `#029CF5` даёт только 2.97:1 — ниже нормы
   4.5:1 и ниже 3:1 для крупного/жирного текста. `#029CF5` остаётся для
   наведения, ссылок, фокуса и информационного цвета, где на нём не
   белый текст.
2. **Кнопка Danger — заливка `#C62828`, не эталонный Error `#F13636`.**
   Белый текст на `#F13636` даёт 3.95:1 — ниже нормы. `#F13636` остаётся
   цветом текста/иконок/меток на тёмном фоне (4.2–4.6:1 — достаточно).
3. **Уведомления — приглушённый фон-тон (10%) + цветной текст/рамка**,
   а не сплошная заливка с белым текстом: в референсе показаны только
   иконки-кубики, образца текста уведомления на сплошной заливке нет, а
   сплошная заливка с белым текстом не проходит контраст (Success
   `#00AC4F` + белый = 3.0:1).
4. **Цвета этапов сделок и контрагентов** (5 цветов) в референсе не
   заданы — выведены из общей палитры с проверкой контраста;
   контрагенты переиспользуют часть цветов сделок (см. §1.3).
5. **Заголовки 48/34px** из референса в MVP не используются — для
   плотного интерфейса CRM велики; токены заведены, но не применяются
   нигде, кроме как в будущем.
6. **Шрифт интерфейса меняется** с Instrument Sans на Inter (решение
   владельца) — старый шрифт убирается из `vite.config.js`.
7. **Тёмная поверхность `#1B1F27`** (карточки, поля, шапка таблицы) —
   отдельного образца в референсе нет, выведена чуть светлее фона
   страницы `#131516`.

Если что-то из этого нужно оставить визуально ближе к референсу (даже
ценой контраста) — скажите, какие пункты, и я пересмотрю.
