# Объём первой версии

## Входит в MVP

- Авторизация.
- Приглашение сотрудников по одноразовой ссылке.
- Создание пароля сотрудником.
- Блокировка учётной записи.
- Два уровня доступа: создатель и участник.
- База клиентов.
- База контрагентов.
- Сделки.
- Канбан сделок.
- Канбан контрагентов.
- API заявок с сайта.
- Нормализация телефонных номеров.
- Поиск существующего клиента.
- Создание новой сделки у существующего клиента.
- Задачи.
- Собственные календари у сделок и задач.
- Договоры и документы.
- История изменений.
- Дашборд с базовой аналитикой.
- Тёмная тема.
- Слияние дублей клиентов.
- Адаптивный интерфейс, в том числе для iPhone: левое меню на компьютере,
  нижняя панель вкладок на телефоне (`docs/17-ui-screens.md`).
- PWA: установка на домашний экран iPhone (`docs/16-pwa-and-mobile.md`).
- Уведомления в Telegram (бот @CRM_fortunabellabot).
- Push-уведомления на iPhone — делаются последними в этапе PWA; если
  возникнут проблемы с iOS, остальной MVP не блокируют, а Telegram
  остаётся резервным каналом.


## Отложить на следующие версии

- определение обязательных и необязательных полей для заполнения в карточках
  (в MVP обязательны только минимальные: например, у клиента — имя)
- построение обязательных связей (например нельзя переместить сделку в отмененные если не указана причина отказа)
- Приём писем с корпоративной почты.
- Статистику посещений сайта.
- Расширенную аналитику.
- Массовый экспорт.
- Сложный офлайн-режим.
- Интеграцию с дополнительными каналами.
