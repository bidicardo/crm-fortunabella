# Задачи и календарь

## Задача

Задача — отдельное действие сотрудника.

Примеры:
- позвонить клиенту;
- отправить договор;
- проверить оплату;
- связаться с контрагентом;
- обзвонить контрагентов.

Название задачи является своболным текстовым полем

## Поля задачи

- Название.
- Описание.
- Дата.
- Время.
- Статус.
- Ответственный.
- Связанная сделка.
- Связанный клиент.
- Связанный контрагент.
- Настройка напоминания.
- Дата создания.
- Дата изменения.

## Статусы

- новая;
- в работе;
- выполнена;
- отменена.

## Связи

Задача может быть:
- связана со сделкой;
- связана с клиентом;
- связана с контрагентом;
- независимой.

## Единый календарь

Календарь содержит переключатели:
- мероприятия;
- задачи;

## Главный календарь

На главной странице отображается мини-версия календаря со сделками.
Из неё можно перейти в полный календарь.

## Уведомления

Уведомления создаются:
- о новых заявках;
- о приближении задачи;
- о просроченной задаче;
- о мероприятии сегодня;
- о предстоящем мероприятии.
