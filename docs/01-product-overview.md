# Обзор продукта

## Название

Fortuna bella CRM.

## Назначение

CRM для управления клиентами, сделками,
контрагентами, задачами, календарём и договорами
в сфере проведения выездного фан-казино.

## Сайт лендинга

https://fortunabella.ru

## Основные понятия

### Клиент

Физическое лицо или организация, заказавшие мероприятие.

### Сделка

Процесс продажи конкретного мероприятия.

В рамках текущего проекта сделка и мероприятие
являются одним объектом.

Вся информация по мероприятию заполняется в карточке сделки. В CRM понятие сделки и мероприяте это одно и то же. Но во всем проекте нужно использовать термин "сделка"

### Контрагент

Ресторан, агентство, ведущий, площадка, судоходная
компания или другая организация, связанная с мероприятием
либо привлечением клиента.

### Задача

Действие сотрудника, например:
- позвонить клиенту;
- отправить договор;
- проверить оплату;
- связаться с контрагентом.

Заполняется в свободной форме.

## Основная цель

Создать self-hosted CRM с:
- базой клиентов;
- базой контрагентов;
- воронками продаж;
- канбаном;
- задачами;
- календарём;
- документами;
- API для заявок с лендинга;
- PWA-интерфейсом для iPhone.
