# Воронка контрагентов

## Этапы

1. Первый контакт.
2. Дожим.
3. Сотрудничаем.
4. Отказ.

## Возможности

Канбан контрагентов должен поддерживать:
- отображение карточек контрагентов;
- drag-and-drop;
- сенсорное перемещение;
- переход в карточку контрагента;
- добавление нового контрагента;
- сортировку;
- выбор отображаемых полей;
- сохранение этапа;
- подсчёт количества карточек в колонке.

## Как устроен канбан (задача 23)

- Адрес `/counterparties` — главный вид раздела «Контрагенты»; 4 колонки
  в порядке этапов, в заголовке — метка этапа его цветом и число карточек.
- Карточка: название (ссылка на карточку контрагента), тип, телефон,
  первое контактное лицо; видимые поля выбираются кнопкой «Поля карточки»
  и запоминаются в браузере. Новый контрагент — кнопкой «Новый
  контрагент» или «+» в колонке (сразу на этап колонки); новая карточка
  встаёт в конец колонки.
- Перенос — перетаскиванием (встроенный `wire:sort` Livewire 4, без
  отдельных пакетов) между колонками и внутри колонки; на телефоне —
  после удержания пальцем 0,3 с, чтобы прокрутка не начинала перенос.
  Сервер принимает только этапы из списка и существующих контрагентов;
  смена этапа пишется в историю, порядок колонки пересчитывается одним
  запросом (служебное поле `position`, в историю не пишется).
- Без перетаскивания этап меняется списком на карточке (в конец колонки).
- Порядок карточек: «Вручную» (как расставили, по умолчанию), «По
  названию», «По дате создания»; не в ручном режиме перенос внутри
  колонки порядок не меняет, между колонками — работает.
- На телефоне блок канбана прокручивается вбок сам, страница — нет;
  кнопки не мельче 44 px. Вид по референсу 8 — шаг Д-23.
