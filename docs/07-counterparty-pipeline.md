# Воронка контрагентов

## Этапы

1. Первый контакт.
2. Дожим.
3. Сотрудничаем.
4. Отказ.

## Возможности

Канбан контрагентов должен поддерживать:
- отображение карточек контрагентов;
- drag-and-drop;
- сенсорное перемещение;
- переход в карточку контрагента;
- добавление нового контрагента;
- сортировку;
- выбор отображаемых полей;
- сохранение этапа;
- подсчёт количества карточек в колонке.

## Действующие контрагенты

База действующих контрагентов формируется
из контрагентов, находящихся на этапе «Сотрудничаем».
