# Критерии приёмки

## Пользователи

- Создатель может создать одноразовую ссылку.
- Участник может зарегистрироваться по ссылке.
- Использованная ссылка больше не работает.
- Участник может войти по своему паролю.
- Создатель может заблокировать участника.
- Участник не может приглашать пользователей.

## Клиенты

- Можно создать клиента.
- Можно изменить клиента.
- Можно открыть карточку клиента.
- В карточке отображаются все его сделки.
- Номер телефона нормализуется.
- Повторный номер вызывает предупреждение.
- Можно объединить две карточки.

## Сделки

- Можно создать сделку.
- Сделка связывается с клиентом.
- Сделка связывается с контрагентом.
- Сделку можно перемещать между всеми этапами.
- В колонках отображаются количество и сумма.
- Дата сделки отображается в календаре.
- Совпадение дат показывает предупреждение.
- Совпадение дат не блокирует создание.

## Контрагенты

- Можно создать контрагента.
- Можно добавить несколько контактных лиц.
- Контрагента можно перемещать по канбану.
- Этап «Сотрудничаем» отображается в базе действующих контрагентов.

## Лендинг

- API принимает заявку.
- Токен проверяется.
- Имя и телефон обязательны.
- Создаётся клиент и сделка.
- Повторная заявка связывается с существующим клиентом.
- Исходная заявка сохраняется в журнале.
- Отправляется уведомление.

## Задачи

- Можно создать независимую задачу.
- Можно связать задачу со сделкой.
- Можно изменить статус задачи.
- Задача отображается в календаре.
- Работает напоминание.

## Документы

- Можно загрузить PDF.
- Можно загрузить DOC/DOCX.
- Можно скачать файл с телефона.
- Документ отображается в связанных карточках.
- Можно удалить документ.

## PWA

- Приложение устанавливается на iPhone.
- Канбан работает касанием.
- Все страницы открываются на мобильном экране.
- Push работает после разрешения.
- При запрете push CRM продолжает работать.
