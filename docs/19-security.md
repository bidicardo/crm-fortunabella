# Безопасность

## Авторизация

- Пароли хранятся в хешированном виде.
- Доступ только после авторизации.
- Открытая регистрация запрещена.
- Регистрация возможна только по приглашению.

## Приглашения

- Одноразовый токен.
- Ограниченный срок действия.
- Нельзя повторно использовать токен.
- Нельзя передавать пароль через URL.
- Использовать HTTPS.

## API лендинга

- Секретный токен.
- Проверка входной схемы.
- Rate limit — не более одного запроса с одного IP за интервал
  (по умолчанию 60 секунд, см. `docs/13-landing-api.md`).
- Honeypot-поле (`company`) — скрытое поле формы, заполняется только
  ботами; при заполнении заявка отбрасывается, но ответ выглядит как
  успешный (200 `{"ok": true}`), чтобы не выдавать наличие защиты.
- Защита от повторной обработки.
- Журнал запросов.
- Не хранить токен в исходном коде.

## Файлы

- Ограничение типов файлов.
- Ограничение размера файлов.
- Проверка расширения и MIME-типа.
- Безопасные имена файлов.
- Запрет выполнения загруженных файлов.

## Данные

- Не хранить секреты в Git.
- Не использовать реальные данные клиентов в тестах.
- Регулярно создавать резервные копии.
- Использовать HTTPS.
