# Воронка сделок

## Название

Канбан сделок.

## Этапы

1. Новая заявка.
2. В работе.
3. Бронь.
4. Проведена.
5. Отказ.

## Карточка канбана

Карточка болжна включать в себя:
- название сделки;
- имя клиента;
- сумму;
- дату проведения;
- этап (статус сделки);
- источник лида;
- статус предоплаты;
- ответственного сотрудника.

## Возможности

- Drag-and-drop между колонками.
- Перемещение с помощью сенсорного экрана.
- Переход в карточку сделки.
- Добавление новой сделки.
- Сортировка по атрибутам.
- Выбор отображаемых атрибутов.
- Подсчёт количества сделок в колонке.
- Подсчёт суммы сделок в колонке.
- Сохранение нового этапа в базе.

## Переходы

- Любую сделку можно переместить в любую стадию.
- Система может показывать предупреждения.
- Система не должна блокировать перемещение.
