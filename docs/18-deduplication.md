# Дубли и слияние клиентов

## Поиск дублей

Проверять:
- нормализованный телефон;
- email;

## Предупреждение

При создании клиента система показывает:
- найденную похожую карточку;
- совпавшие поля;
- кнопку открыть существующего клиента;
- кнопку продолжить создание.

## Слияние

Пользователь выбирает:
- основную карточку;
- карточку-дубль.

Система показывает:
- поля обеих карточек;
- сделки;
- задачи;
- документы;
- историю изменений.

## Результат

- Все сделки переносятся на основного клиента.
- Все задачи переносятся на основного клиента.
- Все документы переносятся на основного клиента.
- История объединения сохраняется.
- Дублируемая карточка архивируется.
- Физическое удаление не выполняется автоматически.

## Доступ

- слияние доступно только создателю;
- слияние доступно всем участникам.
