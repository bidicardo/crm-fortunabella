# Клиенты

## Поля клиента

Обязательное поле — только имя (или название организации).
Остальные необязательны.

- Имя или название организации (обязательно).
- Телефон — только российский, 11 цифр, хранится как `+7XXXXXXXXXX`.
- Email.
- Социальная сеть или мессенджер.
- Юридический тип.
- Роль.
- Удобное время для связи.
- Примечания.
- Дата создания.
- Дата изменения.
- История изменений.

## Тип клиента

Хранится двумя отдельными полями:
- юридический тип: физическое лицо / организация (выбор из списка);
- роль: свободный текст без заданных вариантов (например, «невеста»,
  «организатор», «администратор»).

## Телефон

Допускаются только российские номера: после удаления всех нецифровых
символов должно остаться 11 цифр, первая — 7 или 8 (8 заменяется на 7).
Иностранные и не сводящиеся к этому формату номера отклоняются.
Правило единое для ручного ввода и заявок с лендинга (`docs/13-landing-api.md`).

## Карточка клиента

Карточка должна содержать:
- основные данные;
- все сделки клиента;
- задачи;
- документы;
- историю изменений;
- возможность перейти в связанную сделку.

## База клиентов

- Табличный список.
- Поиск.
- Фильтрация.
- Сортировка.
- Выбор отображаемых колонок.
- Фильтрация по статусу сделок.
- Цветовое обозначение строки по статусу сделки.
- Экспорт в Excel — опционально.
- Слияние дублей.

## Слияние дублей

Любой пользователь CRM (создатель или участник)
может выбрать две карточки и объединить их.

Перед объединением нужно показать:
- основную карточку;
- карточку-дубль;
- поля, которые будут сохранены;
- сделки;
- задачи;
- документы;
- историю.

Дублируемая карточка архивируется.
Физическое удаление не является обязательным.
