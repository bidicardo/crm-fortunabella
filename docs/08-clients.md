# Клиенты

## Поля клиента

- Имя или название организации.
- Телефон.
- Email.
- Социальная сеть или мессенджер.
- Тип клиента.
- Удобное время для связи.
- Примечания.
- Дата создания.
- Дата изменения.
- История изменений.

## Тип клиента


Предварительные значения:
- физическое лицо;
- компания;
- невеста;
- организатор;
- администратор.

Рекомендуется разделить:
- юридический тип: физическое лицо / организация;
- роль: частный заказчик / невеста / организатор / администратор / другое.

## Карточка клиента

Карточка должна содержать:
- основные данные;
- все сделки клиента;
- задачи;
- документы;
- историю изменений;
- возможность перейти в связанную сделку.

## База клиентов

- Табличный список.
- Поиск.
- Фильтрация.
- Сортировка.
- Выбор отображаемых колонок.
- Фильтрация по статусу сделок.
- Цветовое обозначение строки по статусу сделки.
- Экспорт в Excel — опционально.
- Слияние дублей.

## Слияние дублей

Создатель или пользователь с соответствующим правом
может выбрать две карточки и объединить их.

Перед объединением нужно показать:
- основную карточку;
- карточку-дубль;
- поля, которые будут сохранены;
- сделки;
- задачи;
- документы;
- историю.

Дублируемая карточка архивируется.
Физическое удаление не является обязательным.
