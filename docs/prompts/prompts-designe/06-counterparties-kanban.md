# Дизайн задачи 23 — Канбан контрагентов (Д-23, референс 8)

Фаза 3. Логика задачи 23 готова: этапы, перетаскивание (`wire:sort`
Livewire 4, без пакетов), счётчики, смена этапа списком на карточке,
сортировка, «Поля карточки». Компонент — `app/Livewire/CounterpartyBoard.php`,
шаблон — `resources/views/livewire/counterparty-board.blade.php`.

Решения владельца (октябрь 2026):

1. **Прокрутка внутри колонки.** Сейчас, когда карточек больше, чем
   помещается по высоте, прокручивается вся страница. Нужно: канбан
   занимает высоту экрана, каждая колонка прокручивается вертикально
   сама, как отдельный блок; заголовок колонки (этап, счётчик, «+»)
   остаётся на месте. И на компьютере, и на телефоне.
2. **Цвет этапа на карточке** (`refs/08-kanban-color-lines-ref.png`):
   у каждой карточки сбоку слева — вертикальная цветная линия цвета её
   этапа; список смены этапа на карточке окрашен в цвет этапа.
3. **Канбан сделок будет оформлен иначе**, чем канбан контрагентов.
   Д-23 делается только для контрагентов; общие компоненты «на вырост»
   для сделок не выносить, дизайн канбана сделок — отдельно в Д-28
   (`08-deals-kanban.md`).
4. **Колонки во всю ширину на компьютере.** Колонки вместе занимают всю
   ширину области канбана, свободного места справа нет: колонки делят
   ширину поровну и растягиваются вместе с окном. Если окно настолько
   узкое, что колонка стала бы уже удобной минимальной ширины, — включается
   горизонтальная прокрутка блока канбана (не страницы). Телефон — как
   сейчас: колонки фиксированной ширины, блок листается вбок.

Цвета этапов уже есть в дизайн-системе (`--color-stage-*` в
`resources/css/app.css`, обе темы), этап → цвет — `CounterpartyStage::tone()`:
Первый контакт — синий, Дожим — фиолетовый, Сотрудничаем — зелёный,
Отказ — красный.
