# Промпты дизайна

Промпты для Claude Code по внедрению дизайна. План, порядок и обоснование —
`docs/26-ui-designe-plan.md`; референсы и иконки — `docs/design/`.
Каждый шаг — отдельный файл; внутри файла промпт в блоке кода, его
целиком копируют в Claude Code.

## Как пользоваться

1. Дизайн для разделов Фаз 3–9 **идёт отдельным проходом сразу после
   логики задачи**: сначала задача работает на компонентах дизайн-системы
   (Д1), затем запускается дизайн-промпт и меняет только вёрстку. Так
   логику и оформление можно проверять и откатывать по отдельности.
2. Перед запуском проверь, что референс лежит в `docs/design/refs/`, а
   нужные иконки в `docs/design/icons/`. Каждый промпт сам требует сначала
   разобрать референс и показать спецификацию; кода до подтверждения нет.
3. Промпты Фаз 3–10 написаны заранее и опираются на текущие документы. Перед
   запуском сверь блок «Уточнить перед запуском» и названия файлов с
   реальным кодом: имена компонентов и маршрутов к тому моменту могут
   отличаться.
4. Ничего не коммитится без явной просьбы; после каждого шага — проверка
   на компьютере и на iPhone в обеих темах, затем коммит.

## Общие правила (входят в каждый промпт)

- Сначала прочитать референс и документы, показать короткую спецификацию
  и список файлов, дождаться подтверждения.
- Логику, данные, поля и тексты интерфейса не менять; если референс
  требует нового, задать вопрос.
- Использовать компоненты дизайн-системы, цвета и шрифты из общих
  переменных; собственных длинных наборов классов на страницах не писать.
- Светлая и тёмная темы; вид на iPhone по `docs/16-pwa-and-mobile.md`
  (шрифт полей 16 px, `min-h-dvh`, безопасная зона, без горизонтальной
  прокрутки страницы, элементы нажатия не меньше 44 px).
- Сохранить доступность (`aria-label`, `aria-current`, подписи полей) —
  тесты на неё опираются.
- Новых зависимостей не устанавливать без подтверждения; иконки — только
  встроенные SVG.
- В конце: `npm run build`, `composer check` (и в Sail), `git status` и
  `git diff`, ничего не коммитить, честно написать, что не проверено без
  браузера, и дать чек-лист ручной проверки.
