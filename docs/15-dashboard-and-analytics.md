# Дашборд и аналитика

## Главная страница

Главная страница содержит:
- календарь;
- базовую аналитику;
- список ближайших мероприятий;
- новые задачи;
- новые заявки;
- другие полезные виджеты.

## Показатели MVP

- количество новых заявок за период;
- количество сделок на каждом этапе;
- сумма сделок по этапам;
- сумма оплаченных предоплат;
- количество проведённых мероприятий;
- количество отказов;
- конверсия из заявки в проведённое мероприятие;
- ближайшие мероприятия;
- новые заявки за сегодня.

## Периоды

Нужно определить фильтры:
- сегодня;
- неделя;
- месяц;
- квартал;
- произвольный период.

## Расширенная аналитика

Открывается со страницы дашборда.

В будущем можно добавить:
- аналитику по источникам лидов;
- аналитику по сотрудникам;
- аналитику по контрагентам;
- среднюю сумму сделки;
- среднее время до брони;
- процент отмен;
- повторных клиентов.

## Статистика лендинга

Количество посетителей сайта не входит
в обязательный MVP.

Для реализации потребуется интеграция
с системой веб-аналитики.
